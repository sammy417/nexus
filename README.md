# NEXUS

개인 주식 포트폴리오 관리 웹 앱 MVP (Next.js App Router + TypeScript + Tailwind CSS).

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 접속.

## 휴대폰 없이 PC에서 테스트하기

이 앱은 모바일 퍼스트로 설계되어 있어서, 전체 화면(`max-w-md`)이 항상 폰 너비 카드 형태로 가운데 정렬됩니다. 즉 **PC 브라우저 창을 그냥 넓게 열어도 자동으로 폰 화면처럼 보입니다** — 별도 설정 없이 바로 확인 가능합니다.

더 실제 기기에 가깝게(디바이스 프레임, 터치 시뮬레이션 등) 보고 싶다면 브라우저 개발자도구의 반응형 모드를 사용하세요.

- Chrome / Edge: `F12` → 좌측 상단 기기 아이콘 클릭 (또는 `Ctrl+Shift+M` / Mac: `Cmd+Shift+M`) → 상단에서 "iPhone 14 Pro" 등 기기 선택
- Safari: 개발자 메뉴 → "반응형 웹 디자인 모드"

### 반복 테스트를 위한 초기화

거래 내역은 브라우저 `localStorage`에 저장되어 새로고침해도 유지됩니다. 시나리오를 처음부터 다시 테스트하고 싶다면 헤더 좌측 상단의 초기화(↺) 아이콘을 눌러 더미 데이터로 되돌릴 수 있습니다.

### 확인해볼 시나리오 예시

1. 하단 네비 "거래 추가" → 신규 종목 매수 → 대시보드/포트폴리오에 새 종목이 반영되는지 확인
2. 이미 보유한 종목을 다른 단가로 추가 매수 → 평단가가 가중평균으로 재계산되는지 확인
3. 보유 수량 일부만 매도 → 수량만 줄고 나머지는 유지되는지 확인
4. 보유 수량 전부 매도 → 목록에서 종목이 사라지는지 확인
5. 보유 수량보다 많은 수량을 매도 시도 → 폼이 닫히지 않고 에러 메시지가 뜨는지 확인
6. 새로고침(F5) 후에도 위 변경 사항이 유지되는지 확인
7. 헤더의 ↺ 버튼으로 초기 상태로 재설정
